03

Source code and setup

Read the source code or run the demo on your computer.

The GitHub repository has the source code, setup instructions and an offline demo with fictional data. A hosted public application is not available yet.

GitHub →Setup guide →

1. Try the offline demo

If you have Git and Python 3.12 or newer installed, run:

git clone https://github.com/Vipront/careeros.git
cd careeros
python scripts/demo.py

The demo uses three fictional vacancies and illustrative scores. It needs no credentials or extra Python packages, makes no network requests and creates no database.

2. Explore the local dashboard

Follow the README to create a virtual environment, install requirements-demo.txt, add the demo data and set a local password. Then start the Streamlit dashboard. The guide has commands for Windows and macOS/Linux.

3. Configure your own profile

For the full workflow, follow the README: replace the example profile, review the document templates and configure the services you need. This takes additional setup beyond the offline demo.
