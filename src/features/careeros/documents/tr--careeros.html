01

CareerOS'u neden geliştirdim?

İlanları incelemeyi ve başvuru hazırlığını kolaylaştırmak istedim.

Moleküler biyoloji ve genetik alanında iş ararken bu işleri kolaylaştırmak için CareerOS'u geliştirdim. Kariyerinin başındaki başka yaşam bilimleri adaylarının da ilanları değerlendirmesine ve başvuru koşullarını anlamasına yardımcı olup olamayacağını denemek istiyorum.

02

Geliştirdiğim başvuru akışı

Hedeflediğim akış, ilanları değerlendirmeyi ve başvuru hazırlığını kapsıyor. Açık demoyu kurgu verilerle bilgisayarında deneyebilirsin.

01

02

Başvuru koşullarını incele

İstenen becerileri, deneyimi ve uygunluk koşullarını kendi profilinle karşılaştır.

Başvurunu hazırla

İlana uygun belgeleri hazırla, gözden geçir ve hangilerini göndereceğine karar ver.

03

Kaynak kod ve kurulum

Kaynak kodu incele veya demoyu bilgisayarında çalıştır.

GitHub deposunda kaynak kod, kurulum yönergeleri ve kurgu verilerle çalışan çevrimdışı demo var. Herkese açık bir web uygulaması henüz bulunmuyor.

GitHub →Kurulum rehberi →

1. Çevrimdışı demoyu dene

Git ve Python 3.12 veya üzeri kuruluysa şu komutları çalıştır:

git clone https://github.com/Vipront/careeros.git
cd careeros
python scripts/demo.py

Demo, üç kurgu ilan ve temsili puan kullanıyor. Erişim anahtarı veya ek Python paketi gerektirmiyor; ağa bağlanmıyor ve veritabanı oluşturmuyor.

2. Paneli bilgisayarında aç

README'yi izleyerek sanal ortamı oluştur, requirements-demo.txt paketlerini kur, demo verilerini ekle ve yerel parolayı belirle. Ardından Streamlit panelini başlat. Rehberde Windows ve macOS/Linux komutları bulunuyor.

3. Kendi profiline göre yapılandır

Tam akış için README'yi izle: örnek profili kendi bilgilerinle değiştir, belge şablonlarını gözden geçir ve ihtiyacın olan servisleri yapılandır. Bu akış, çevrimdışı demoya ek kurulum gerektiriyor.
